# Grey Clover Labs Website

A premium AI business automation landing page for **Grey Clover Labs** — built with pure HTML, CSS, and JavaScript.

## 🚀 Live Demo

Deployed on Vercel: [grey-clover-labs.vercel.app](https://grey-clover-labs.vercel.app)

---

## 📁 Project Structure

```
grey-clover-labs-website/
├── index.html       ← Main page (all sections)
├── styles.css       ← Premium light theme (Royal Blue + Crimson Red)
├── script.js        ← Animations, ROI calculator, dashboard, simulator
├── vercel.json      ← Vercel deployment config
└── README.md        ← This file
```

---

## ✨ Features

- **Hero section** with animated live AI dashboard mockup
- **ROI Calculator** — interactive sliders showing time/money saved
- **Before vs. After Simulator** — 4 business scenarios
- **Animated stats counter** — scrolls up as you reach the section
- **Comparison table** — GreyClover vs Agencies vs In-House
- **Contact form** with smooth success state
- **Fully responsive** — mobile, tablet, desktop
- **Premium light theme** — Royal Blue (#1A4ED8), Crimson Red (#D4172A), Antique Gold

## 🛠️ Local Development

No build tools needed — it's plain HTML/CSS/JS.

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/grey-clover-labs-website.git
cd grey-clover-labs-website

# Open directly in browser
open index.html

# Or use VS Code Live Server for hot reload
```

---

## 📦 Deploy to Vercel

### Option 1 — One-click from GitHub (Recommended)
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **Add New Project**
3. Import the GitHub repository
4. Click **Deploy** — done!

### Option 2 — Vercel CLI
```bash
npm install -g vercel
vercel login
vercel --prod
```
